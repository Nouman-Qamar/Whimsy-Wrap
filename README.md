# Whimsy-Wrap — Bracelet Store Website

A 4-page e-commerce front-end for a bracelet/jewelry boutique — home, products, about, and contact — built with vanilla HTML and CSS.

🔗 **Live Demo:** https://nouman-qamar.github.io/Whimsy-Wrap/

## Pages
- **Home** (`index.html`) — hero, featured bracelets
- **Products** (`products.html`) — full bracelet catalog
- **About** (`about.html`) — brand story
- **Contact** (`contact.html`) — contact details/form

## Bug Fixed
All 7 product/about images (`bracelet1.jpg`–`bracelet6.jpg`, `about-image.jpg`) were referenced but never existed anywhere in the repo — every image was a broken link. Replaced with real placeholder photography for the demo.

## Tech Stack
`HTML5` · `CSS3` · Font Awesome icons

## Run It Locally
```bash
git clone https://github.com/Nouman-Qamar/Whimsy-Wrap.git
cd Whimsy-Wrap
python3 -m http.server 8000
```
